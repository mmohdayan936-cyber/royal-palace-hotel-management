# Royal Palace Hotel — Hotel Management System

Simple B.Tech CSE mini project using Python Flask + SQLite, customized for Royal Palace Hotel, Lucknow.

## Features
- Admin login
- Dashboard
- Room management
- Customer management
- Room booking
- Check-in/check-out
- Automatic bill calculation
- Payment status
- Printable bill

## Run
1. Install Python 3.
2. Open terminal in this folder.
3. Run:
   pip install -r requirements.txt
4. Run:
   python app.py
5. Open:
   http://127.0.0.1:5000

The SQLite database `hotel.db` is created automatically on first run.
